# actor-kenkyusha — research-frontier knowledge actor

`actor-kenkyusha` detects research frontiers, proposes hypotheses, and gathers
citation-grounded evidence across public academic disciplines. Its canonical
repository is `kotoba-lang/actor-kenkyusha`; the `actor-` prefix identifies its
governed executable role.

The actor owns a reusable research-knowledge workflow. It does not own
etzhayyim's religious Charter, Council, or organism state. Existing
`did:web:etzhayyim.com:actor:kenkyusha`, AT Protocol namespaces, Radicle
identity, and former GitHub URL remain compatibility identities.

See `CLAUDE.md` for the architecture and `clojure -M:test` for the executable
contract suite.
